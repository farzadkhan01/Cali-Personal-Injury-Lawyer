# Cali Personal Injury Lawyer — Design System

## Design Philosophy

The visual identity combines:

**Legal Authority**

- **Editorial Sophistication**
- **Glassmorphism**
- **3D Abstract Minimalism**

The result should feel premium, calm, modern and trustworthy.

---

# 1. COLOR SYSTEM

The palette should primarily use restrained neutral colors.

Core categories:

- Deep Ink
- Soft Charcoal
- Warm White
- Cool White
- Soft Gray
- Glass White
- Glass Dark
- Muted Accent
- Accent Highlight

The accent should be subtle.

Avoid overly saturated neon colors.

---

# 2. BACKGROUND

Backgrounds should create depth.

Possible techniques:

- Soft gradients
- Radial gradients
- Subtle grain
- Large blurred shapes
- Atmospheric lighting
- Very subtle color transitions

Background effects must not reduce readability.

---

# 3. GLASSMORPHISM

Glass surfaces may use:

- Semi-transparent backgrounds
- backdrop-filter blur
- Thin translucent borders
- Soft shadows
- Subtle highlights
- Layered opacity

Example conceptual treatment:

```css
background: rgba(...);
backdrop-filter: blur(...);
border: 1px solid rgba(...);
```
