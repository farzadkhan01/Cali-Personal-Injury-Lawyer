````md
# Cali Personal Injury Lawyer — Component System

## Component Philosophy

Components should be reusable, visually consistent, and easy to replace.

Avoid giant page components.

Avoid duplicated UI.

---

# GLOBAL COMPONENTS

Potential shared components:

- Header
- DesktopNavigation
- MobileNavigation
- Footer
- Container
- Section
- SectionHeading
- Button
- GlassCard
- Badge
- ArrowButton
- ImageFrame
- Stat
- Divider
- Reveal
- TextReveal

---

# NAVIGATION

Navigation should include:

- Brand
- Primary links
- Primary CTA
- Mobile menu

Navigation may use glassmorphism.

It should remain readable against all backgrounds.

---

# BUTTONS

Variants:

- Primary
- Secondary
- Ghost
- Icon
- Pill

Buttons should support:

- Hover
- Focus
- Active
- Disabled

---

# GLASS CARD

Reusable glass component supporting:

- Light variant
- Dark variant
- Strong blur
- Soft blur
- Border
- Optional hover state

Do not overuse.

---

# SECTION HEADING

Should support:

- Eyebrow
- Heading
- Description
- Alignment
- Width

---

# STAT

Reusable for verified statistics.

Example structure:

```text
VALUE
Label
Supporting context
```
````
